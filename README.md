# Цифровий слід і репутація

Інтерактивна сторінка до уроку інформатики в 6 класі (урок 26 за КТП: «Культура представлення себе у мережі. Цифровий слід. Цифрова репутація»).

На сторінці:

- що таке цифровий слід, активний і пасивний слід;
- гра «Активний чи пасивний?» (10 дій);
- що лишається після видалення допису;
- цифрова репутація: «Один допис — різні думки»;
- гра «Публікувати чи ні?» (8 ситуацій);
- конструктор безпечного профілю зі шкалою ризику;
- фільтр чернетки перед публікацією;
- що робити, якщо в мережі ображають;
- самоперевірка на 8 питань і домашнє завдання «Мій слід за день».

Уся сторінка — один файл `index.html` без збирання. Теорія — за підручником «Формула», с. 106–111. Імена й нікнейми на сторінці вигадані.
